## Cara Menjalankan Program

Prasyarat: .NET SDK (versi 8.0 / 10.0 atau lebih baru).

1. Buka terminal atau Command Prompt.
2. Masuk ke folder pertemuan yang ingin dijalankan:
   ```bash
   cd Pertemuan-01-Pengenalan-Framework
   ```
3. Jalankan aplikasi:
   ```bash
   dotnet run
   ```
