# Pertemuan 04: WPF Rich UI - Form Registrasi Mahasiswa

## 📌 Deskripsi Singkat
Pertemuan ini berfokus pada pengenalan Windows Presentation Foundation (WPF) dan bahasa deklaratif XAML. Mahasiswa merancang formulir pendaftaran identitas mahasiswa dengan komponen input standar seperti `TextBox`, `ComboBox`, `RadioButton`, `DatePicker`, dan `Button`.

## 🎯 Target Pengerjaan
1. Desain antarmuka formulir registrasi mahasiswa menggunakan XAML.
2. Pengambilan nilai input dari kontrol UI dan validasi dasar (cek input kosong).
3. Menampilkan hasil input atau konfirmasi melalui `MessageBox.Show()` / ringkasan visual.
4. Dokumentasi laporan dan tangkapan layar form input di Notion.
