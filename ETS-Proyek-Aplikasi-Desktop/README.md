# ETS: Proyek Aplikasi Desktop PBKK

## 📌 Deskripsi Singkat
Evaluasi Tengah Semester (ETS) merupakan kulminasi materi paruh pertama mata kuliah PBKK C. Mahasiswa membangun sebuah aplikasi desktop utuh berbasis C#, WPF, dan Microsoft SQL Server berdasarkan spesifikasi PRD yang telah dirancang pada Pertemuan 07.

## 🎯 Target Pengerjaan
1. Implementasi kode program aplikasi desktop WPF yang fungsional dan estetis.
2. Integrasi penuh dengan database SQL Server untuk manajemen data persisten.
3. Fitur lengkap sesuai rancangan PRD (Validasi, CRUD, Filter/Pencarian, Pengelolaan Transaksi/Entitas).
4. Laporan komprehensif di Notion dilengkapi panduan instalasi, demo fitur, dan arsitektur sistem.
