# Pertemuan 02: .NET Framework & Aplikasi Console CRUD

## 📌 Deskripsi Singkat
Pertemuan ini membahas pemanfaatan .NET SDK untuk membuat aplikasi berbasis teks (Console App) dengan menu interaktif. Mahasiswa mengimplementasikan fungsionalitas CRUD (*Create, Read, Update, Delete*) sederhana menggunakan struktur koleksi `List<T>` di memori.

## 🎯 Target Pengerjaan
1. Pembuatan proyek console menggunakan .NET SDK.
2. Implementasi menu interaktif CLI (Tambah, Tampilkan, Ubah, Hapus Data Mahasiswa).
3. Kode bersih, terstruktur di `Program.cs` tanpa *over-engineering*.
4. Dokumentasi laporan dan tangkapan layar pengujian menu di Notion.
