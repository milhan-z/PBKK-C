# Pertemuan 01: Pengenalan Framework & Program Manajemen Data Dasar

## 📌 Deskripsi Singkat
Pertemuan ini membahas konsep dasar kerangka kerja (*framework*), perbedaannya dengan pustaka (*library*), arsitektur ekosistem .NET, serta latihan implementasi program C# sederhana untuk manajemen data mahasiswa berbasis console (*in-memory*).

## 🎯 Target Pengerjaan
1. Rangkuman konsep dasar framework dan ekosistem .NET.
2. Program C# Console dasar untuk input dan menampilkan data mahasiswa.
3. Dokumentasi laporan dan tangkapan layar eksekusi program di Notion.
