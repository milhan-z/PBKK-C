# Pertemuan 06: Integrasi WPF dengan Database SQL Server

## 📌 Deskripsi Singkat
Pertemuan ini membahas persistensi data dengan menghubungkan aplikasi desktop WPF ke database Microsoft SQL Server (atau SQL Server LocalDB / Express). Mahasiswa mengimplementasikan query ADO.NET (`SqlConnection`, `SqlCommand`, `SqlDataReader` / `SqlDataAdapter`) untuk operasi CRUD langsung ke tabel database.

## 🎯 Target Pengerjaan
1. Skrip DDL/DML tabel database mahasiswa di SQL Server.
2. Konfigurasi connection string yang aman dan jelas.
3. Fungsi CRUD (SELECT, INSERT, UPDATE, DELETE) yang tersambung ke `DataGrid`.
4. Dokumentasi laporan, skrip database, dan bukti tersimpannya data di Notion.
