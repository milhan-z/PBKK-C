# Pertemuan 05: Pendalaman WPF - Student Management System

## 📌 Deskripsi Singkat
Pertemuan ini melanjutkan eksplorasi WPF dengan mengimplementasikan sistem manajemen data mahasiswa yang lebih komprehensif. Mahasiswa memanfaatkan komponen `DataGrid` untuk menampilkan daftar data dari koleksi in-memory serta menyediakan aksi tambah, edit, dan hapus data.

## 🎯 Target Pengerjaan
1. Desain antarmuka dashboard / tabel data menggunakan `DataGrid`.
2. Pengelolaan koleksi data mahasiswa di memori (`ObservableCollection` atau `List`).
3. Operasi CRUD sederhana langsung melalui event handler UI.
4. Dokumentasi laporan dan tangkapan layar tabel data di Notion.
