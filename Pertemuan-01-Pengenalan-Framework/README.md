# Pertemuan 01: Pengenalan Framework & Program Data Mahasiswa

Folder ini memuat implementasi kode program dan dokumentasi pengujian untuk materi Pertemuan 01 mata kuliah Pemrograman Berbasis Kerangka Kerja (PBKK) C.

## Deskripsi Singkat
Latihan pemrograman dasar C# Console menggunakan class entitas `Mahasiswa` dan koleksi `List<T>` di memori. Program menyediakan antarmuka teks berbasis menu untuk menambah data, menampilkan tabel data, dan mencari data berdasarkan NRP.

## Struktur Berkas
- `Program.cs`: Berkas utama program C# (model entitas, data awal, dan logika menu).
- `Pertemuan-01-Pengenalan-Framework.csproj`: Konfigurasi proyek .NET 10.0 Console.
- `screenshots/terminal_run.png`: Tangkapan layar eksekusi terminal saat program dijalankan.

## Cara Menjalankan
Pastikan .NET SDK telah terinstal di komputer.

```bash
cd Pertemuan-01-Pengenalan-Framework
dotnet run
```
