## Pola Umum Pengerjaan & Pengumpulan Mahasiswa PBKK C

Berdasarkan data pengumpulan di [Looker Studio Monitoring Kelas](https://datastudio.google.com/u/0/reporting/88c27138-fb61-43d5-a032-8b87ebb9bd4c/page/TfwbD?s=hZooHbACi_0), berikut adalah pola standar yang digunakan teman-teman sekelasmu dalam mengerjakan dan mengumpulkan tugas:

1. **Platform Dokumentasi (Link yang Dikumpulkan ke Form/Database):**
   - Mayoritas mahasiswa membuat artikel dokumentasi di **Blogspot** pribadi (`*.blogspot.com`), **Medium** (`medium.com`), atau halaman publik **Notion** (`notion.site` / `app.notion.so`).
   - Di dalam artikel tersebut, mahasiswa menyertakan tautan menuju **Repositori GitHub** untuk *source code* lengkap serta dokumentasi tangkapan layar (*screenshot*) atau video demo YouTube.
2. **Struktur Artikel Pengumpulan:**
   - **Identitas Mahasiswa:** Nama, NRP, Kelas (PBKK C), dan nomor pertemuan/tugas.
   - **Deskripsi Singkat & Landasan Teori:** Penjelasan singkat mengenai konsep atau *framework* yang digunakan pada pertemuan tersebut (misalnya konsep .NET, WinForms, WPF, XAML, atau SQL Server).
   - **Kode Program (*Source Code*):** Potongan kode utama (`Program.cs`, `MainWindow.xaml`, `MainWindow.xaml.cs`, atau skema query SQL) beserta tautan repositori GitHub.
   - **Hasil Eksekusi (*Screenshot Output*):** Tangkapan layar tampilan antarmuka aplikasi saat dijalankan (input data, validasi, tabel CRUD, hingga hasil penyimpanan di database).
3. **Status Pengumpulan Kelas PBKK C Saat Ini:**
   - Pada periode aktif di [Database Monitoring Kelas Looker Studio](https://datastudio.google.com/u/0/reporting/88c27138-fb61-43d5-a032-8b87ebb9bd4c/page/TfwbD?s=hZooHbACi_0), kelas **PBKK C** telah memiliki rekaman pengumpulan aktif dari **Pertemuan 1 hingga Pertemuan 7 serta Evaluasi Tengah Semester (ETS)** (fokus pada ekosistem Desktop .NET, C#, WinForms, WPF, dan SQL Server).
   - Untuk **Pertemuan 8 hingga Pertemuan 16 dan EAS** (paruh kedua semester pasca-ETS), kurikulum [Blog PBKK Fajar Baskoro](https://fajarbaskoro.blogspot.com/2019/02/pbkk-1.html) dan riwayat kelas PBKK beralih ke pengembangan **Aplikasi Web & Mobile berbasis Framework** (.NET Web Application/API, .NET MAUI/Xamarin, CodeIgniter MVC, dan Laravel CRUD).

## Detail Pengerjaan & Checklist Per Pertemuan (Pertemuan 1 – ETS)

Gunakan daftar periksa (*checklist*) di bawah ini untuk melengkapi satu per satu tugasmu dari Pertemuan 1 hingga ETS:

### Pertemuan 1: Pengenalan Framework & Program Manajemen Data Dasar
- **Materi Referensi:** [Pengenalan Framework](https://fajarbaskoro.blogspot.com/2021/03/framework-kerangka-kerja-adalah-istilah.html) pada [Blog PBKK Fajar Baskoro](https://fajarbaskoro.blogspot.com/2019/02/pbkk-1.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Merangkum konsep dasar kerangka kerja (*framework*), perbedaan *library* vs *framework*, serta manfaat penggunaan *framework* dalam rekayasa perangkat lunak.
  - [ ] Membuat program C# sederhana untuk manajemen data/database mahasiswa (input Nama, NRP, Jurusan/Kelas, serta menampilkan daftar data).
  - [ ] Menulis artikel laporan di Blogspot/Notion berisi penjelasan kode dan *screenshot* output, lalu menginput URL ke form pengumpulan kelas.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh laporan [Yasmina Fitri Azizah - Tugas 1](https://yaminazh.blogspot.com/2026/09/pbkk-tugas-1.html) dan [Mayandra Suhaira Frisiah - Tugas Pertemuan 1](https://mayandrasf.blogspot.com/2026/09/pbkk-tugas-pertemuan-1.html) yang memuat struktur program manajemen data mahasiswa dasar beserta *screenshot* terminal.

### Pertemuan 2: .NET Framework & Aplikasi Console CRUD
- **Materi Referensi:** [.NET Framework](https://fajarbaskoro.blogspot.com/2019/02/net-framework.html) dan [Membuat Aplikasi dengan .NET](https://fajarbaskoro.blogspot.com/2019/02/membuat-aplikasi-dengan-net.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Menginstal .NET SDK dan Visual Studio / VS Code.
  - [ ] Membuat proyek C# Console Application (`dotnet new console`) untuk latihan dasar ("Hello World") dilanjutkan dengan aplikasi menu interaktif berbasis teks (CRUD sederhana: Tambah, Lihat, Ubah, Hapus data di memori).
  - [ ] Mendokumentasikan arsitektur CLR (*Common Language Runtime*) & BCL (*Base Class Library*) pada .NET beserta kode program dan hasil *run* aplikasi.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh [Kukuh Putra Purwanegara - Latihan 1 Aplikasi Berbasis .NET](https://kukuhputrac27.blogspot.com/2026/10/latihan-1-membuat-aplikasi-berbasis.html), [Faizal Aldy Armiriawan - Latihan 1 .NET Framework](https://fazdy99.blogspot.com/2026/10/latihan-1-dotnet-framework.html), dan [Mohamad Valdi Ananda](https://docs.shinyshoe.net).

### Pertemuan 3: Aplikasi Desktop GUI (Kalkulator Sederhana / Saintifik)
- **Materi Referensi:** [Latihan Aplikasi Desktop 1](https://fajarbaskoro.blogspot.com/2019/02/latihan-aplikasi-desktop-1.html), [.NET Desktop Application](https://fajarbaskoro.blogspot.com/2019/02/net-desktop-application.html), dan materi pendukung [Aplikasi Media Capture](https://fajarbaskoro.blogspot.com/2019/02/aplikasi-media-capture.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Membuat proyek Desktop Application menggunakan **Windows Forms (WinForms)** atau **WPF** di Visual Studio.
  - [ ] Merancang form kalkulator yang memiliki tombol angka (`0-9`), tombol operator dasar (`+`, `-`, `*`, `/`, `=`, `C`/`Clear`), atau fungsi tambahan kalkulator saintifik.
  - [ ] Menulis logika *event handler* (`Button_Click`) di C# untuk memproses perhitungan dan menampilkan hasilnya di *TextBox* / *Label* layar kalkulator.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh [Kukuh Putra Purwanegara - Latihan 2 Membuat Kalkulator Sederhana](https://kukuhputrac27.blogspot.com/2026/10/latihan-2-membuat-kalkulator-sederhana.html), [Faizal Aldy Armiriawan - Latihan 2 Kalkulator Desktop](https://fazdy99.blogspot.com/2026/10/latihan-2-kalkulator-desktop.html), dan [Jahhaza Assiqooyah N. - Latihan 3 Calculator App](https://jahhazassq.blogspot.com/2026/10/latihan-3-calculator-app.html).

### Pertemuan 4: Rich UI dengan WPF (Student Registration App / Entry Form)
- **Materi Referensi:** [WPF - Windows Presentation Foundation](https://fajarbaskoro.blogspot.com/2019/02/wpf-windows-presentation-foundation.html), [Latihan WPF](https://fajarbaskoro.blogspot.com/2019/02/latihan-wpf.html), dan [UWP - Universal Windows Platform](https://fajarbaskoro.blogspot.com/2019/02/uwp-universal-windows-platform.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Membuat aplikasi WPF menggunakan bahasa *markup* **XAML** untuk merancang tata letak formulir input (*Grid*, *StackPanel*, *TextBox*, *ComboBox*, *RadioButton*, *DatePicker*, dan *Button*).
  - [ ] Mengimplementasikan form **Registrasi Identitas Mahasiswa (*Student Registration App*)** atau sistem manajemen perpustakaan sederhana yang menerima input pengguna dan menampilkannya ke daftar/pesan konfirmasi.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh [Kukuh Putra Purwanegara - Latihan 3 Registrasi Identitas](https://kukuhputrac27.blogspot.com/2026/10/latihan-3-registrasi-identitas.html), [Faizal Aldy Armiriawan - Latihan 3 Student Registration App](https://fazdy99.blogspot.com/2026/10/latihan-3-student-registration-app.html), dan [Very Ardiansyah - Latihan 4 Library Management](https://veryardiansyah.blogspot.com/2026/10/latihan-4-library-management.html).

### Pertemuan 5: Pendalaman WPF & Student Management System
- **Materi Referensi:** [Windows Presentation Foundation (Pendalaman)](https://fajarbaskoro.blogspot.com/2019/02/windows-presentation-foundation.html) dan [Latihan WPF - Membuat Dashboard](https://fajarbaskoro.blogspot.com/2019/02/latihan-wpf-membuat-dashboard.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Mengembangkan antarmuka WPF yang lebih lengkap berupa **Student Management System (*Student Manager*)** atau Dashboard aplikasi desktop.
  - [ ] Menerapkan komponen *DataGrid* / *ListView*, *Data Binding* (`ObservableCollection`), serta fitur tambah, edit, filter, dan hapus data mahasiswa pada antarmuka WPF, sekaligus menyiapkan rancangan tabel untuk integrasi database.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh [Faizal Aldy Armiriawan - Latihan WPF Student Management System](https://fazdy99.blogspot.com/2026/10/latihan-wpf-student-management-system.html), [Very Ardiansyah - Latihan 5 Student Management System](https://veryardiansyah.blogspot.com/2026/10/latihan-5-student-management-system.html), dan [Yasmina Fitri Azizah - Tugas 5](https://yaminazh.blogspot.com/2026/10/pbkk-tugas-5.html).

### Pertemuan 6: Integrasi Aplikasi WPF dengan Database SQL Server
- **Materi Referensi:** [SQL Server](https://fajarbaskoro.blogspot.com/2019/02/sql-server.html) dan [Desain Aplikasi Desktop](https://fajarbaskoro.blogspot.com/2019/02/desain-aplikasi-desktop.html).
- **Apa yang Harus Dikerjakan:**
  - [ ] Menyiapkan *instance* database **SQL Server** (melalui SSMS / SQL Server Express / LocalDB) dan membuat database serta tabel mahasiswa.
  - [ ] Menghubungkan aplikasi WPF (*Student Registration* / *Student Management System*) ke SQL Server menggunakan `SqlConnection` / `Microsoft.Data.SqlClient` atau Entity Framework.
  - [ ] Mengimplementasikan operasi **CRUD persisten** (`INSERT`, `SELECT`, `UPDATE`, `DELETE`) langsung ke tabel SQL Server dan menampilkannya di *DataGrid* WPF.
- **Cara Teman Sekelas Mengerjakan:**
  - Lihat contoh [Faizal Aldy Armiriawan - Latihan Student Registration SQL Server](https://fazdy99.blogspot.com/2026/10/latihan-student-registration-sql-server.html), [Very Ardiansyah - Latihan 6 SQL Server](https://veryardiansyah.blogspot.com/2026/10/latihan-6-sql-server.html), dan [Yasmina Fitri Azizah - Tugas 6](https://yaminazh.blogspot.com/2026/10/pbkk-tugas-6.html).

### Pertemuan 7 & Evaluasi Tengah Semester (ETS): Proyek Aplikasi Desktop & PRD

  - [ ] Membangun aplikasi desktop utuh berbasis **WPF + SQL Server** (dikerjakan secara berkelompok/individu sesuai kesepakatan kelas) dengan studi kasus nyata.
  - [ ] Mengunggah dokumentasi proyek, kode sumber GitHub, dan tangkapan layar/demo aplikasi untuk penilaian Pertemuan 7 dan ETS.

## Urutan Langkah Praktis untuk Melengkapi Tugasmu

- [ ] **Langkah 1 (Siapkan Blog/Notion & GitHub):** Buat satu blog khusus di Blogspot atau workspace publik di Notion untuk menampung laporan Pertemuan 1 sampai terakhir, serta akun GitHub untuk menyimpan setiap folder proyek latihan.
- [ ] **Langkah 2 (Selesaikan Tugas Konsol & Kalkulator - Pertemuan 1–3):** Kerjakan proyek C# Console (Manajemen Data Mahasiswa & CRUD dasar) untuk Pertemuan 1–2, lalu buat proyek WinForms/WPF Kalkulator untuk Pertemuan 3.
- [ ] **Langkah 3 (Bangun Proyek Sekuensial WPF + SQL Server - Pertemuan 4–6):** Buat satu proyek WPF **Student Registration / Student Management System** yang bertahap—mulai dari desain form XAML (Pertemuan 4), pengelolaan daftar/dashboard (Pertemuan 5), hingga koneksi CRUD ke database SQL Server (Pertemuan 6) sehingga kamu tidak perlu membuat tiga aplikasi yang benar-benar terpisah dari nol.
- [ ] **Langkah 4 (Susun PRD & Proyek Desktop - Pertemuan 7 & ETS):** Buat dokumen PRD dan aplikasi desktop WPF + SQL Server bertema sistem informasi (atau lengkapi dokumentasi individu dari proyek kelompokmu di kelas PBKK C).
- [ ] **Langkah 5 (Submit ke Database Kelas):** Pastikan setiap tautan artikel per pertemuan sudah memiliki izin akses publik (*public*) sebelum dimasukkan ke form pengumpulan yang terhubung ke [Looker Studio Monitoring Kelas](https://datastudio.google.com/u/0/reporting/88c27138-fb61-43d5-a032-8b87ebb9bd4c/page/TfwbD?s=hZooHbACi_0).
