# Pertemuan 03: Aplikasi Desktop GUI - Kalkulator Sederhana

## 📌 Deskripsi Singkat
Pertemuan ini merupakan langkah awal memasuki pengembangan aplikasi desktop berbasis Graphical User Interface (GUI). Fokus utama adalah merancang antarmuka kalkulator dengan tombol angka, operator aritmatika, serta menghubungkan event handler tombol (*Code-Behind*) untuk memproses kalkulasi.

## 🎯 Target Pengerjaan
1. Pembuatan proyek Desktop Application (WPF / WinForms).
2. Tata letak grid tombol kalkulator (`0-9`, `+`, `-`, `*`, `/`, `=`, `Clear`).
3. Logika perhitungan standar menggunakan event handler `btn_Click` yang mudah dipahami.
4. Dokumentasi laporan dan tangkapan layar pengujian perhitungan di Notion.
