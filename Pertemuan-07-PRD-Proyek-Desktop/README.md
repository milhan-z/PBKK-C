# Pertemuan 07: Product Requirement Document (PRD) & Perancangan Proyek ETS

## 📌 Deskripsi Singkat
Pertemuan ini berfokus pada tahapan perancangan sistem sebelum implementasi proyek Evaluasi Tengah Semester (ETS). Mahasiswa menyusun dokumen PRD (*Product Requirement Document*) yang mendefinisikan latar belakang masalah, kebutuhan fungsional dan non-fungsional, perancangan skema database (ERD), serta mockup/wireframe antarmuka pengguna.

## 🎯 Target Pengerjaan
1. Dokumen PRD terstruktur untuk tema aplikasi desktop yang dipilih.
2. Deskripsi use case dan persona pengguna.
3. Desain tabel relasional dan diagram alir.
4. Dokumentasi laporan perancangan di Notion sebagai pondasi proyek ETS.
